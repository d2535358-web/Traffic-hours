## Project Description

Traffic congestion is a common problem in urban areas. Predicting traffic volume can help in traffic management, planning, and reducing congestion.

This project uses Machine Learning techniques to predict traffic volume based on factors such as weather conditions, temperature, time of day, holidays, and other environmental conditions.

---

## Objectives

- Predict traffic volume using Machine Learning.
- Analyze the relationship between time and traffic volume.
- Compare different regression algorithms.
- Identify the best-performing model.
- Classify traffic conditions into Low, Medium, and High levels.
- Evaluate traffic-level predictions using accuracy and confusion matrices.

---

## Dataset

The project uses the Metro Interstate Traffic Volume dataset.

The dataset contains traffic volume observations along with weather and time-related information.

### Important Features

- Temperature
- Rain
- Snow
- Cloud coverage
- Weather condition
- Holiday
- Hour
- Day of week
- Month
- Year

### Target

**Traffic Volume**

---

## Machine Learning Algorithms

Three regression algorithms are used:

1. Linear Regression
2. Random Forest Regressor
3. Gradient Boosting Regressor

---

## Data Preprocessing

The following preprocessing steps are performed:

- Handling missing values
- Converting date and time information
- Extracting hour, day, month and year
- Identifying weekends
- Encoding categorical features
- Splitting the dataset into training and testing data

---

## Model Evaluation

The regression models are evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

For additional traffic-level analysis, traffic volume is divided into:

- Low
- Medium
- High

The traffic-level predictions are evaluated using:

- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-Score
